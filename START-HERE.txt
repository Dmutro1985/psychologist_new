КОМПЛЕКТ ОНОВЛЕННЯ 20260920-3

1. Не видаляйте свій попередній проєкт.
2. Натисніть на ZIP правою кнопкою -> Видобути все.
3. Відкрийте у VS Code нову розпаковану папку psychologist.
4. У цій папці відкрийте index.html через Open with Live Server.
5. Натисніть Ctrl+Shift+R. Не відкривайте стару вкладку зі старою папкою.

Очікуваний вигляд:
- форма запису на світло-зеленому фоні, у світлій картці;
- на широкому екрані вступ ліворуч, форма праворуч;
- на телефоні вступ і форма одна під одною;
- на сторінці «Контакти» немає міста, адреси та карти.

Усі авторські стилі розташовані в css/style.css.
HTML-сторінки підключають CSS та JS версії 20260920-3.
Якщо стилі не завантажилися або завантажилися старі, вгорі сторінки
з'явиться повідомлення з поясненням.

Цей архів містить клієнтську частину: сторінки, CSS, JS, шрифти, зображення.
Серверні PHP-файли та налаштування пошти навмисно не включені.
На хостингу збережіть існуючі send-form.php, nbu-rates.php та конфігурацію.
Не видаляйте інші файли хостингу при оновленні.
Live Server і GitHub Pages не виконують PHP: надсилання форми там
не працюватиме. Для реального надсилання потрібен ваш PHP-хостинг.
Посилання Telegram та календар є альтернативними способами запису.
Не надсилайте тестових заявок із чужими або реальними клієнтськими даними.
